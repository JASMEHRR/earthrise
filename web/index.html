Earthrise shows whatever your Spotify account is playing, on any device. Set it up once:

  1. Make a free Spotify app. On your phone or PC open developer.spotify.com/dashboard, log in, and press Create app. Any name and description work.
  2. Add the redirect address. Under Redirect URIs type exactly and press Add. If you will also use the TV app, add earthrise://callback too.
  3. Tick Web API, agree to Spotify's terms, and press Save.
  4. Copy your Client ID from the app's Basic Information page and paste it here. Already built into this app.
  5. Connect. Log in with your email and password (Google and Facebook buttons do not work inside TV apps), then press Agree.
  6. Play any song on your phone, PC or TV. It shows up here within a few seconds.

Choosing, pausing and skipping songs from here need Spotify Premium. Showing songs, lyrics and visuals works on free accounts. If Spotify says your account is not registered, add your email under User Management in the dashboard.

Music video background (optional)

Earthrise can play each song's music video, muted, behind the record. Finding the videos needs a free YouTube key:

  1. Open console.cloud.google.com, log in, and create a project. Any name works.
  2. Search for YouTube Data API v3 and press Enable.
  3. Open Credentials, press Create credentials, then API key. Under API restrictions, allow only YouTube Data API v3.
  4. Paste the key here. Already built into this app.
  5. In Settings, set Background to Music video.

The free limit covers about 100 new songs a day. Songs already found are remembered, so replays cost nothing.
